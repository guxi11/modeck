标题：把 AI 配置和技能，收成一副牌

正文：
Claude Code 一套配置，Codex 又一套，切换项目还要重新整理规则和技能。

做了个小工具 modeck：集中管理个人与团队配置，把规则、技能和外部 Git 资源组合成不同工作模式，再按项目加载。自动选择逻辑由自己定义，也可以给项目固定组合。

外部资源支持安装、锁定版本和主动更新。希望把重复整理配置的时间，留给真正要做的事。

主页：https://guxi11.com/modeck/
开源：https://github.com/guxi11/modeck
